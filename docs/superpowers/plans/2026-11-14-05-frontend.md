# Frontend Implementation Plan (Plan 5 of 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A mobile-first single-page app with two zones — a GC dashboard (the bid's subs in a risk table sorted by `risk_raw`, expandable breakdown, search-to-add) and a foreman chat (bid as context, answers rendering citations as osha.gov links).

**Architecture:** `apps/web` is a Vite + React + TypeScript app. A thin `api.ts` client calls `@ssi/api` over HTTP. Pure helpers (risk band, citation rendering) are unit-tested; UI is assembled from small components (`BidTable`, `ContractorRow`, `AddSub`, `Chat`). No state library — React state + fetch is enough for this scope.

**Tech Stack:** Vite, React 18, TypeScript, vitest + @testing-library/react (one logic test), plain CSS (mobile-first). Prereq: Plan 3 API running on `http://localhost:3001`.

```ts
export type Band = 'HIGH' | 'MEDIUM' | 'LOW' | 'NONE';
export function band(score: number | null): Band {
  if (score == null || score <= 0) return 'NONE';
  if (score >= 60) return 'HIGH';
  if (score >= 25) return 'MEDIUM';
  return 'LOW';
}
```

- [ ] **Step 3: `api.ts` client**

```ts
export interface BidRow {
  contractorId: number | null; name: string; status: string;
  riskRaw: number | null; riskScore: number | null;
  fatalities: number | null; serious: number | null; inspections: number | null;
}
export interface Citation { type: string; activity_nr?: number; summary_nr?: number; url: string }
export interface ChatResponse { answer: string; citations: Citation[] }

const base = '/api';
export async function getBid(id: number): Promise<BidRow[]> {
  return (await fetch(`${base}/bids/${id}`)).json();
}
export async function searchContractor(name: string, state?: string) {
  const q = new URLSearchParams({ name, ...(state ? { state } : {}) });
  return (await fetch(`${base}/contractors/search?${q}`)).json() as Promise<{ contractor_id: number; display_name: string; confidence: number }[]>;
}
export async function chat(bidId: number, bidName: string, message: string): Promise<ChatResponse> {
  return (await fetch(`${base}/chat`, {
    method: 'POST', headers: { 'content-type': 'application/json' },
    body: JSON.stringify({ bidId, bidName, message }),
  })).json();
}
```

### Task 4: Foreman chat with citation links

**Files:**
- Create: `apps/web/src/components/Chat.tsx`

- [ ] **Step 1: Implement**

```tsx
import { useState } from 'react';
import { chat, type Citation } from '../lib/api.js';

interface Msg { role: 'user' | 'assistant'; text: string; citations?: Citation[] }

export function Chat({ bidId, bidName }: { bidId: number; bidName: string }) {
  const [msgs, setMsgs] = useState<Msg[]>([]);
  const [input, setInput] = useState('');
  const [busy, setBusy] = useState(false);

  async function send() {
    const q = input.trim();
    if (!q || busy) return;
    setMsgs((m) => [...m, { role: 'user', text: q }]);
    setInput(''); setBusy(true);
    try {
      const res = await chat(bidId, bidName, q);
      setMsgs((m) => [...m, { role: 'assistant', text: res.answer, citations: res.citations }]);
    } catch {
      setMsgs((m) => [...m, { role: 'assistant', text: 'Error contacting the assistant.' }]);
    } finally { setBusy(false); }
  }

  return (
    <section>
      <h2>Ask the foreman assistant</h2>
      <div>
        {msgs.map((m, i) => (
          <div key={i} className={`card msg-${m.role}`}>
            <div>{m.text}</div>
            {m.citations && m.citations.length > 0 && (
              <div style={{ marginTop: 6, fontSize: 12 }}>
                {m.citations.map((c, j) => (
                  <a key={j} href={c.url} target="_blank" rel="noreferrer" style={{ marginRight: 8 }}>
                    {c.type === 'incident' ? `incident ${c.summary_nr}` : `inspection ${c.activity_nr}`}
                  </a>
                ))}
              </div>
            )}
          </div>
        ))}
      </div>
      <div className="row">
        <input style={{ flex: 1 }} value={input} placeholder="Which of my subs has the most falls?"
          onChange={(e) => setInput(e.target.value)} onKeyDown={(e) => e.key === 'Enter' && send()} />
        <button onClick={send} disabled={busy}>{busy ? '…' : 'Send'}</button>
      </div>
    </section>
  );
}
```
